# CursoAgentes
Repositorio del curso de Agentes

Username : LisSanchez-DS

El presente es un repositorio para guardar los cuadernos ejecutados del curso de agentes de Hugging Face
Todos los cuadernos fueron desarrollados en paralelo con sus componentes en el curso.

NOTA: Las diferencias de código entre este cuaderno y el original de Hugging Face se dieron a problemas de créditos
para utilizar los modelos propuestos. Se utilizó un modelo alterno de Google y el código fue cambiado con ayuda de la IA Claude sólo para este propósito.
